# Results Directory

This directory contains all outputs generated from analyses in this research project.

## Directory Structure

### `models/`
**Purpose:** Saved trained model objects and configurations.

**Contents:**
- Serialized model objects (`.pkl`, `.joblib`, `.pt`)
- Model hyperparameters (`.json`)
- Training logs and learning curves
- Cross-validation fold information

**Structure:**
```
models/
├── logistic_regression/
│   ├── model_fold_0.pkl
│   ├── model_fold_1.pkl
│   ├── ...
│   ├── hyperparameters.json
│   ├── training_log.json
│   └── cv_results.json
├── xgboost/
├── lightgbm/
└── catboost/
```

**Guidelines:**
- One subdirectory per model type
- Include metadata for reproducibility
- Track hyperparameter search results

### `predictions/`
**Purpose:** Model predictions on test/validation sets.

**Contents:**
- Predicted probabilities and class labels
- True labels for evaluation
- Prediction metadata (model version, timestamp, dataset)

**Format:**
- Parquet files with columns: `y_true`, `y_pred`, `y_proba`, `fold`, `model`
- JSON metadata files

**Guidelines:**
- Predictions enable downstream analysis without re-running models
- Include prediction metadata for traceability
- Use consistent naming: `{dataset}_{model}_predictions.parquet`

### `metrics/`
**Purpose:** Computed performance, fairness, and calibration metrics.

**Contents:**
- Performance metrics (AUROC, AUPRC, accuracy, etc.)
- Fairness metrics (demographic parity, equalized odds, etc.)
- Calibration metrics (Brier score, ECE, MCE)
- Statistical test results
- Confidence intervals

**Format:**
- CSV/Parquet for tabular metrics
- JSON for nested/hierarchical metrics
- LaTeX tables for manuscript

**Structure:**
```
metrics/
├── performance_by_model.csv
├── fairness_metrics.csv
├── calibration_metrics.csv
├── statistical_tests.json
├── bootstrap_ci.json
└── metrics_metadata.json
```

### `figures/`
**Purpose:** Generated visualizations and plots.

**Contents:**
- Exploratory data analysis plots
- Model performance curves (ROC, PR)
- Fairness visualizations
- Calibration plots
- Diagnostic plots

**Structure:**
```
figures/
├── exploratory/          # EDA plots
├── model_performance/    # ROC, PR, learning curves
├── fairness/            # Disparity plots, group comparisons
├── calibration/         # Reliability diagrams
├── diagnostics/         # Residuals, influence, etc.
└── publication_ready/   # High-res, styled for manuscript
```

**Guidelines:**
- Save both `.png` (for notebooks) and `.pdf` (for publication)
- Use consistent styling and color schemes
- Include titles, labels, and legends
- High resolution (300 DPI minimum for publication)
- Meaningful filenames describing content

### `tables/`
**Purpose:** Generated tables for manuscript and supplementary materials.

**Contents:**
- Descriptive statistics tables
- Model comparison tables
- Fairness audit results
- Statistical test results

**Formats:**
- `.csv` - Raw data
- `.xlsx` - Formatted for review
- `.tex` - LaTeX for manuscript
- `.md` - Markdown for easy viewing

**Structure:**
```
tables/
├── table1_sample_characteristics.csv
├── table2_model_performance.csv
├── table3_fairness_audit.csv
├── table4_sensitivity_analysis.csv
├── supplementary_tables.xlsx
└── latex/
    ├── table1.tex
    ├── table2.tex
    └── ...
```

## Naming Conventions

**Models:**
- `{model_type}_fold_{k}.{ext}`
- Example: `logistic_regression_fold_0.pkl`

**Predictions:**
- `{dataset}_{model}_predictions.parquet`
- Example: `compas_xgboost_predictions.parquet`

**Figures:**
- `{description}_{model/group}.{ext}`
- Example: `roc_curve_xgboost.pdf`

**Tables:**
- `table{n}_{description}.{ext}`
- Example: `table1_sample_characteristics.csv`

## Reproducibility

All results can be regenerated by running the analysis notebooks in order:

```bash
# Run all notebooks
jupyter nbconvert --execute notebooks/**/*.ipynb

# Or use the master runner
python scripts/run_all_experiments.py --full
```

## Version Control

Results files are gitignored to avoid repository bloat. Only small summary files and metadata are committed. To reproduce:

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run notebooks or master script
4. Results will be generated in this directory
